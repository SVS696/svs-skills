# Упрощённый технический русский

Учитывайте, кто будет читать документ и для чего он ему нужен. Если в проекте есть словарь, используйте его. При переводе на русский сверяйтесь с оригиналом.

Если дан только один текст, проверьте его ясность и внутреннюю согласованность. Если даны исходник и новая редакция, сравните их. Например, если в исходнике написано «оператор вправе отменить заявку», а в редакции — «оператор должен отменить заявку», укажите, что право превратилось в обязанность.

1. **Выберите правила.** Для любой задачи прочитайте [правила УТР](references/rules.md) и [рабочий словарь](references/glossary.md). Начните с разделов своего жанра. Для постановки, технического задания, API, протокола, скилла или решения прочитайте [прикладное расширение](references/extensions.md). Для проверки по конкретному ГОСТу сверьте редакцию, область применения и требуемые пункты по [указателю оригиналов](references/sources.md).
2. **Зафиксируйте смысл.** Для каждого изменяемого правила определите, кому оно адресовано, при каком условии действует, что предписывает или разрешает, какой результат наблюдает читатель. Отметьте исключения, числа с единицами, границы, точные имена, порядок действий, причину и открытые вопросы. Выбирайте термин по определению, контексту и проектному словарю.
3. **Подготовьте запрошенный результат.** В режиме адаптации верните текст в исходной структуре. Если нужен файл, внесите правку в указанный файл. В режиме проверки сохраните исходник и укажите место, спорный фрагмент, изменение смысла или две возможные трактовки и минимальную правку. В режиме адаптации с проверкой сначала дайте готовый текст, затем перечислите вопросы, которые остались открытыми.
4. **Сверьте результат.** Сопоставьте каждое изменённое правило с источником. Проверьте, что на штатном и пограничном примере читатель получит тот же ответ. Порядок сверки и образцы замечаний приведены в [проверке на примерах](references/check.md). Для неопределённости, которая меняет действие, задайте вопрос. Если владелец решения известен, укажите его.

Для инструкции проверьте также, понятно ли читателю, что сделать дальше и когда остановиться.

Для формальной проверки укажите документ, редакцию, область и проверенные пункты. Обычная языковая редактура покрывает только рассмотренный текст. Если запрошенный нормативный первоисточник недоступен, укажите, какую часть заключения можно подтвердить.
