# Как проверить текст и смысл

Используйте этот порядок при проверке спорного фрагмента. Глубину сверки определяет смысл изменения. Перечень ниже помогает редактору сравнить версии. В готовый документ передавайте результат, который запросил читатель.

1. Найдите соответствующие места исходника и редакции. Установите, кто что делает, с какой обязательностью и при каких условиях, если эти различия есть в тексте. Сопоставьте затронутые числа, исключения, технические имена и ссылки.
2. Проверьте, можно ли по новой фразе совершить другое действие, получить другое право или иначе понять результат. Для диапазона проверьте граничное значение. Для исключения сравните случай, на который распространяется правило, и случай, выведенный из его действия. Для переименования достаточно сверить объект и обе надписи.
3. Если заказана проверка, укажите место существенного расхождения, его последствие и минимальную правку. При заказанной адаптации используйте результат сверки для исправления текста. Спросите только о неопределённости, от которой зависит нужный результат.

## Учебные случаи

| Что дал автор | Допустимая редакция | Как отличить смысловую ошибку |
|---|---|---|
| «До передачи в обработку правом отзыва обладает исключительно владелец». | «До передачи в обработку только владелец вправе отозвать заявку», если заявка уже названа в контексте. | До передачи владелец может ничего не делать. Другому участнику это право не предоставлено. Для момента после передачи источник права не устанавливает. Замена «вправе» на «отзывает» теряет выбор. |
| «При температуре 80 °C и выше формируется сигнал, за исключением режима TEST». | «Если температура не ниже 80 °C и режим отличается от `TEST`, система формирует сигнал», если исполнитель «система» определён. | При 79 °C правило не срабатывает. При 80 °C вне `TEST` сигнал требуется. При 80 °C в `TEST` действует исключение. Слово «выше» без «не ниже» исключает ровно 80 °C. |
| «При включённой записи параметры A и B должны записываться либо оба, либо ни один». | «Если запись включена, допускаются два результата: сохранены оба параметра A и B или не сохранён ни один». | Конечное состояние с одним записанным параметром нарушает требование. Способ записи и поведение при сбое здесь не заданы. Одновременность вычисления источник не требует. |
| «Сравните исходный файл и резервный файл. После сравнения удалите его». | Сохраните вопрос «Какой файл удалить после сравнения — исходный или резервный?» | Обе трактовки выполнимы, последствия различаются. Не разрешайте двусмысленность выбором ближайшего существительного. |
| «До окончания проверки сверку проводить нельзя. При её проведении ранее указанного срока результаты могут быть утрачены». | «Не начинайте сверку до окончания проверки. Преждевременная сверка может привести к потере результатов». | Условие видно перед действием. Возможный риск не стал обещанием потери. |
| «Зажать обе клавиши одновременно. По окончании калибровки отпустить». | «Нажмите обе клавиши одновременно и удерживайте их. После окончания калибровки отпустите обе клавиши». | Нажатие первой, затем второй меняет метод. Проверяйте требование к одновременности и момент освобождения. |
| «Ввести значение 2.5 in». Перевод руководства заказан в метрических единицах, дюйм равен 25,4 мм. | «Введите 63,5 мм (2.5 in)», если устройство принимает миллиметры. | Проверьте единицу ввода у устройства. Если поле принимает дюймы, нельзя предписывать ввод 63,5. Оставьте исходную операцию и укажите пересчёт в пояснении. |
| «Если параметра нет, сервер применяет значение 10. При явном null сервер возвращает 400». | «Если поле отсутствует, сервер применяет значение 10. Если поле содержит `null`, сервер возвращает `400`». | Пустая строка — третий случай. Его результат остаётся неизвестным. |
| «В логе зафиксирована отправка. Получение адресатом не проверяли». | «Журнал подтверждает отправку. Получение адресатом не проверяли». | Заключение «адресат получил» добавляет неподтверждённый результат. |
| «Если включён режим А или Б, используйте таблицу 2». О совместимости режимов сведений нет. | «Используйте таблицу 2, если включён режим А или режим Б». Если для задачи нужно описать совмещение режимов, уточните, допускается ли оно и какая таблица тогда применяется. | Для одного режима правило ясно. Слово «ровно» или «оба» добавит ограничение без источника. |

**Проверьте границы примера.** Исходник говорит «при любой другой ошибке показать обычное сообщение». Редакция «при ошибке с другим кодом» исключает ответ без кода. Сохраните исходное условие и в требовании, и в критерии приёмки.

**Запись замечания.** «Раздел “Повтор”, предложение 2. В редакции “оператор должен повторить” разрешение стало обязанностью. Источник разрешает оставить запрос без повтора. Исправить на “оператор вправе повторить”».
