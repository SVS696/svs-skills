# Нормативные источники и локальные оригиналы

Здесь можно найти издание стандарта и проверить нужный пункт. Для языковой правки можно обратиться к отдельной статье [словаря](glossary.md) или [справке по жанру](extensions.md). Для заключения о соблюдении пункта откройте первоисточник в редакции, принятой проектом. Проверьте область применения, формулировку пункта и поправки. Ниже указан состав личной библиотеки на 22 ноября 2026 года.

## Локальные копии

Откройте `standards/` в корне скилла. Каждому PDF в таблице соответствует одноимённый файл с расширением `.md`. В нём есть текст по страницам и ссылки на издание. Таблицы с обычными ячейками записаны в Markdown. Для объединённых ячеек используется HTML-таблица внутри Markdown. У схем, бланков и примеров вёрстки сохранён также вид печатной страницы. Для поиска используйте номер пункта. Перед точным цитированием проверьте формулировку по оригиналу: при распознавании возможны ошибки в буквах, числах и формулах.

Для восстановления библиотеки выполните `python3 scripts/originals.py` из корня скилла. Нужны Python 3.10 или новее, curl, Poppler, Pillow, PyMuPDF, NumPy и opencv-python-headless. Например, при установленном Poppler команду можно выполнить через `uv run --with pillow --with pymupdf==1.27.2.3 --with opencv-python-headless python scripts/originals.py`. Команда использует PDF прежней установки, если он доступен, либо скачивает его во временную папку. Перед конвертацией она сверяет SHA-256 с таблицей. В `standards/` сохраняются Markdown, иллюстрации, их контрольные суммы и два RFC в текстовом формате. Для проверки готовой библиотеки без сети выполните `python3 scripts/originals.py --check`. При переносе скилла для автономной работы включите каталог `standards/`.
