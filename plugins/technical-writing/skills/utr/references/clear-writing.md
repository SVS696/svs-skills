# Как писать кратко и понятно

Шесть приёмов редактуры взяты из статьи Инны Якименко [«Как писать кратко и понятно»](https://protext.su/pro/kak-pisat-kratko-i-ponyatno/), опубликованной «ПроТекстом» 10 января 2014 года. Формулировки и примеры адаптированы для технических постановок и инструкций.

Прочитайте исходную фразу и назовите то, что должен понять читатель. Выберите подходящий приём. После правки сверьте с исходником исполнителя, действие, условия и исключения.

1. Посвятите предложение одной мысли. Две тесно связанные мысли можно оставить вместе. Поставьте условие рядом с действием. Если делите фразу, сохраните связь условия со всеми действиями, к которым оно относится. [Пример с отправкой отчёта](glossary.md#тяжёлые-обороты)
2. Выразите главное подлежащим и сказуемым. «Отчёт содержит итоги проверки» читается проще, чем «Содержанием отчёта являются итоги проверки».
3. Если исполнитель известен и важен, назовите его и используйте действительный залог. «Заявка одобрена комиссией» → «Комиссия одобрила заявку». Если известен только статус, достаточно «Заявка одобрена».
4. Если подряд стоят три существительных или больше, проверьте, можно ли выразить действие глаголом. «Для выполнения проверки подписи» → «Чтобы проверить подпись». Точные названия процедур и полей сохраните.
5. Уберите слова, которые дублируют сказанное. «Верните файл обратно в папку „Входящие“» → «Верните файл в папку „Входящие“». Название папки нужно читателю, чтобы выполнить действие.
6. Длинное перечисление оформите маркированным списком. Пронумеруйте шаги, если их нужно выполнить в заданном порядке.

## Шесть примеров редактуры

В таблице показано, как применить каждое из шести правил к постановке или инструкции.

| Приём | До правки | После правки |
|---|---|---|
| Разделить две мысли | При импорте сервис сверяет код склада со справочником, причём при отсутствии кода в справочнике строка по условиям импорта пропускается. | При импорте сервис сверяет код склада со справочником. Если кода в справочнике нет, сервис пропускает строку. |
| Выразить главное подлежащим и сказуемым | Местом хранения шаблонов является каталог `templates/`. | Шаблоны хранятся в каталоге `templates/`. |
| Назвать исполнителя | Утверждение лимита выполняется руководителем филиала. | Руководитель филиала утверждает лимит. |
| Разобрать цепочку существительных | Для выполнения проверки суммы заказа оператор открывает карточку. | Чтобы проверить сумму заказа, оператор открывает карточку. |
| Убрать повтор | Оператор может по своему желанию скрыть столбец, если захочет. | Оператор может скрыть столбец. |
| Показать порядок шагов | Сначала откройте карточку, а после открытия карточки выберите «История». | 1. Откройте карточку.<br>2. Выберите «История». |
